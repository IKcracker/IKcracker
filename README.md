## 👋 About me

I build business systems that remove manual work: Zoho solutions, API integrations and full-stack web products, taken from scope of work through to production.

- 🏢 **Zoho Developer at [Infolytics SA](https://www.infolytics.co.za)**, a Zoho implementation partner. I joined as an intern in December 2025 and was promoted twice in my first year.
- 🛠️ **Founder of [Code Tech Agency](https://codetechagency.com)**, where I design and build web applications and business software.
- 🎓 Studying towards a **BSc in Computing** at UNISA.

## ⚙️ What I work on

| | |
| --- | --- |
| 🧩 **Zoho development** | Deluge custom functions, workflows, scheduled automations and approval processes across Zoho One, choosing and connecting the apps that fit each business |
| 🔌 **Systems integration** | REST API and webhook integrations between Zoho and external platforms, with callbacks, duplicate prevention and structured error handling |
| 🌐 **Full-stack products** | Next.js, TypeScript, Node.js and PostgreSQL applications, from data model to deployment |
| 🤖 **AI integration** | LLM APIs with tool calling and structured outputs, plus Zoho AI agents and Cliq bots for task tracking and reminders |

Most of my Zoho work is for clients, so that code stays private. I'm happy to talk through how it was built.
